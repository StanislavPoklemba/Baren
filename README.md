# Zum Schwarzen Bären

Website pre hotel a reštauráciu Zum Schwarzen Bären – Lumière Andermatt.

## Technológie

- **Frontend:** React 18, Vite, Tailwind CSS, Framer Motion
- **Backend:** Node.js, Express, Supabase
- **Email:** Resend
- **Jazyky:** EN, DE, FR, IT

## Spustenie

### Frontend
```bash
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```

## Prostredie

Skopíruj `backend/.env.example` do `backend/.env` a doplň prihlasovacie údaje.
